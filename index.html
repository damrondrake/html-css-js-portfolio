    Projects

    KitchenSync

    A full-stack household kitchen management app built with a team of four. KitchenSync tracks pantry inventory in real time across multiple users, sends expiration alerts, and surfaces recipes matched to what you already have on hand. It layers in dietary and allergen onboarding, AI-powered recipe standardization with GPT-4.1, Spoonacular integration, and role-based kitchen membership secured by Supabase Auth and Postgres Row Level Security. Built on Next.js Server Actions and TypeScript with a fully migrated Postgres schema, and deployed to Vercel with per-PR preview environments.

    BudgetBuddy

    A full-stack personal finance dashboard with per-user data isolation and JWT authentication. Track transactions, set category budgets, log income, manage recurring transactions and savings goals, and visualize spending trends with interactive Recharts graphs — plus CSV export and a fully mobile-responsive design. Built with React and Tailwind on a FastAPI + PostgreSQL backend (SQLAlchemy, Alembic-managed migrations); frontend deployed on Vercel and backend on Railway.

    YouTube Ad Skipper

    A Chrome extension (Manifest V3) that automatically skips YouTube ads and mutes the tab during unskippable ones. It uses a MutationObserver on the document body to catch dynamically injected ad UI — no polling or page-load hooks — and persists state across the isolated content script and popup contexts through chrome.storage.local. Handles multiple A/B-tested skip-button selectors for broad compatibility. Built with vanilla JavaScript (ES6+) and the Chrome Extension API.

    SpaceX Informational Website

    A full-stack web application with a React frontend and Node.js / Express backend, integrating a live third-party SpaceX REST API with JWT-based authentication. I configured the deployment pipeline, managed environment variables, and debugged cross-service data flow between the distributed frontend and backend. Backed by MongoDB and deployed to cloud infrastructure on Render.
